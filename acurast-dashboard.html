Alertes Home Assistant

Un téléphone envoie normalement un signal toutes les 30 minutes environ. Vous recevez une alerte s'il se tait plus longtemps que le délai, puis une autre quand il repart.

Téléphones

L'adresse du processor se trouve dans l'app Acurast Processor du téléphone (elle commence par 5).

Actualisation automatique toutes les 60 s. Ouverte depuis le Raspberry Pi, la page affiche l'historique enregistré par le service (un relevé toutes les 5 min) ; ouverte comme simple fichier, elle garde son propre historique dans ce navigateur. Les téléphones n'ont pas de solde propre : leurs frais sont prélevés sur le compte principal. « Tx » = nombre de transactions envoyées (signaux de présence, rapports). Icônes et bandeau générés avec ComfyUI.
